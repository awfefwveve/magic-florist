MAGIC FLORIST v0.3 / 개발 프로젝트
테스터에게는 MagicFlorist-Windows-v0.3.zip을 보내세요.
소스는 Godot 4.7.2 stable에서 project.godot를 열고 F5로 실행합니다.
PLAY.cmd는 Godot 실행 경로 또는 GODOT_BIN이 설정된 개발자용입니다.

MAGIC FLORIST v0.3 / 진행·단골·상점·인테리어 테스트 빌드
작성일: 2026-09-30

실행
ZIP을 전부 압축 해제하고 MagicFlorist.exe를 실행하세요.
Godot 설치나 PLAY.cmd는 필요 없습니다. Windows x64용입니다.

새 게임의 진행
1. 부모님의 운영 안내를 읽고 '꽃집 시작하기'를 누릅니다.
2. 시계로 영업 시작 → 대화 → 주문 수락 → 제작대.
3. 첫 주문은 옐로튼 5송이 꽃다발입니다. 포장지 위에 5송이를 끌어 놓으세요.
4. 가위로 각 꽃의 잎 부분을 드래그 → 손으로 점선 원 안에 모으기.
5. 철사 선택 후 꽃 클릭 → 리본 선택 후 꽃 클릭 → 카운터에서 전달.
6. 상점에서 씨앗 구입 → 재배실에서 씨앗 선택 → 빈 밭 → 물 주기 → 성장 후 수확.
7. 첫 판매 후 2일차에는 화분과 프레지아·러브미스 씨앗이 열립니다.
   두 꽃을 처음 수확하면 사랑 화분 조합법을 발견합니다.
8. 3일차에는 레드 플로아 씨앗이 열립니다. 관련 꽃을 수확하면 생일 꽃다발이 열립니다.

화분 조작
화분 → 흙 선택 후 화분 클릭 → 꽃 최대 2송이 드래그
→ 흙 선택 후 클릭 → 리본 선택 후 클릭 → 카운터에서 전달.
사랑 화분은 프레지아 1송이와 러브미스 1송이입니다.

단골·숙련·엔딩
도감의 단골 탭은 만난 손님의 진행을 보여 줍니다.
인내심 '좋음'에서 주문에 맞게 전달하면 카운트가 증가합니다.
손님에 따라 5/10/15회 달성 시 단골이 되고 이후 주문에 +3/+6/+10% 골드가 붙습니다.
단골이 되면 취향 조합이 공개되고 해당 조합을 주문합니다.
조합법마다 실제로 만들어 판매한 횟수 10회 → 도감에서 숙련 보상 받기.
현재 등록된 조합 3종을 모두 숙련하면 부모님의 계승 편지가 열립니다.
편지를 본 이후에도 영업을 계속할 수 있습니다.

상점과 행상인
상단 상점: 씨앗 묶음 구매, 비료, 6종류의 인테리어.
렌: 2일차부터 3일 간격. 씨앗 50% 할인(방문당 최대 5개), 비료 할인,
성장 물약(활동 시간 180~300초, 성장 1.5배), 제작 부적(1~3일, 꽃 모으기 범위 +50%).
효과가 남아 있는 동안 렌의 다음 방문은 건너뜁니다.
리아: 3일차부터 3일 간격. 정보 1개를 사면 3일 뒤 행사와 관련 꽃을 알려 줍니다.
축제·기념일은 하루, 유행은 이틀. 관련 해금 조합의 주문에 반영됩니다.
정보가 남아 있는 동안 리아는 새 정보를 팔러 오지 않습니다.
행상인과 거래 중에는 시간이 멈춥니다. '구매 종료' 후 시계로 영업을 시작하세요.

인테리어
상점에서 구입한 뒤 '꾸미기'에서 종류 → 색상 → 사용하기.
벽지/바닥: 인내심, 의자/장식 화분: 단골 방문 확률, 액자/시계: 하루 길이.
같은 종류는 한 개만 장착할 수 있습니다. 구입만 한 물건에는 효과가 없습니다.
기본 장식은 효과가 없습니다. 바꾼 모습은 꽃집 준비 화면과 꾸미기 미리보기에 보입니다.

시간·설정
게임 내 활동 시간만 사용합니다. 실제 컴퓨터 시각을 바꿔도 성장하지 않습니다.
기본 하루는 활동 시간 8분, 꽃 성장 4~6분, 손님 대기는 30초씩 4단계입니다.
영업 전·정산·메뉴·행상인·일시정지·백그라운드에서는 시간이 멈춥니다.
다른 창을 보고 돌아오면 '계속하기'를 누르세요.
설정에서 효과음, 큰 본문 글자, 높은 글자 대비를 바꿀 수 있습니다.

기존 저장 및 새 게임 테스트
Windows %APPDATA%/MagicFloristPrototype/ 폴더를 사용합니다.
v0.1/v0.2 저장은 자동 변환합니다. gold/재료/작업/숙련/발견은 가능한 그대로 보존합니다.
원본은 garden.v1-original 또는 garden.v2-original로 따로 남깁니다.
v0.2에서 발견한 4종 꽃은 다시 잠그지 않으므로 새 해금 흐름을 보려면 새 게임이 필요합니다.
새 게임으로 테스트하려면 게임을 종료하고 위 저장 폴더를 다른 이름으로 보관한 뒤 재실행하세요.
저장 파일을 삭제할 필요는 없습니다.

현재 범위
게임 시스템을 연결한 프로토타입입니다. 꽃 4종·조합 3종·단골 대상 10명·장식 18개,
행사 유형 3개를 포함합니다. 정식 일러스트와 음악, 전체 추가 콘텐츠, 모바일 설치 파일,
스토어 연동·코드 서명·실기기 검수는 이번 Windows 기능 구현 범위에 포함되지 않습니다.
확정되지 않은 날짜·가격·추가 대사는 동봉한 구현현황.txt에 표시했습니다.
