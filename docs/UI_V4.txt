Magic Florist v0.4 — UI 배치 / 철사 조작 수정판

ZIP 전체를 새 폴더에 풀고 MagicFlorist.exe를 실행하세요.
Godot 설치, 환경변수 설정, project.godot 열기는 필요 없습니다.
이전 v0.3 실행 파일과 섞지 말고 v0.4 폴더의 실행 파일을 사용하세요.
기존 저장 형식(schema 3)을 유지합니다. 정상 실행은 기존 진행을 이어갑니다.

이번 변경
- 카운터: 왼쪽 손님, 위쪽 대화, 오른쪽 답변, 양옆 이동 화살표.
  날짜/시계는 왼쪽 아래, 책/상점은 오른쪽 아래, 골드/설정은 오른쪽 위.
- 제작대: 위쪽 꽃 선반, 가운데 포장지, 왼쪽 가위, 아래 제작 도구.
- 재배실: 4열 × 3행 텃밭, 아래 물뿌리개/씨앗/비료, 오른쪽 아래 책.
- 주문서: 왼쪽에 펼치는 종이, 대화 이력과 네 단계 색상 인내심 표시.
- 도감: 펼친 책과 왼쪽 색상 탭. 꽃 2×2, 단골 4장씩 페이지 넘기기.

철사 사용법
포장지 → 꽃 5송이 → 가위로 잎 부분을 누른 채 쓸기 → 철사 선택 → 포장지 클릭.
이제 꽃이 서로 가까이 모여 있으면 위치에 관계없이 묶입니다.
처음부터 중앙에 겹쳐 놓았다면 다시 옮길 필요가 없습니다.
철사를 두 번 눌러도 선택이 풀리지 않습니다.
꽃 수/다듬은 수가 부족하면 구체적으로 표시합니다. 철사 후 리본으로 완성합니다.

캐릭터와 꽃 그림은 교체용 임시 에셋입니다. 이번 버전은 보낸 기획 캡처의
UI 위치와 조작 개선에 집중한 Windows 테스트 빌드입니다.
