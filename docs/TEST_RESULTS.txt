Magic Florist v0.4 검증 결과 (2026-09-30)

규칙/저장 회귀 검사: 360개 통과 (v2 148 + v3 189 + 철사 전용 23).
배포 EXE를 한글/공백 경로로 복사해 실행: 1152×720 및 1280×720 모두 UI 오류 0.
Godot 에디터 없이 실행 파일의 내장 프로젝트로 구동.

실제 입력 이벤트 검사
- 시계 → 대화 추가 질문 → 주문 수락 → 왼쪽 주문서 열기/닫기.
- 선반에서 꽃 끌기, 잘못된 위치 반환, 5송이 중앙 중첩 배치.
- 잎을 안 다듬으면 철사 차단, 겹친 꽃 5송이 한 번의 가위질로 다듬기.
- 꽃을 따로 옮기지 않고 철사 사용, 철사 재선택 유지, 넓은 포장지 클릭 판정.
- 리본 마무리 → 카운터 전달 → 정산/배웅.
- 밭 심기/물 주기, 도감 탭/페이지 이동, 씨앗 구매.
- 화분/흙/꽃/흙/리본/전달, 인테리어 구매/색상/장착, 큰 글자 설정.

검증 범위
후반 꽃과 손님 도감, 화분과 인테리어 검사는 테스트 전용 상태를 사용했습니다.
테스트 실행에서는 사용자 저장을 읽거나 덮어쓰지 않았습니다.
모바일 실제 기기 테스트와 모든 가능한 입력 조합의 검증은 포함하지 않습니다.
캐릭터/꽃은 임시 그림이며 기획서의 원화 재현은 이번 변경에 포함하지 않습니다.
실행 환경에서 사용자 폴더 shader cache/인증서 접근 경고가 발생했으며 게임 검사 실패는 없었습니다.
